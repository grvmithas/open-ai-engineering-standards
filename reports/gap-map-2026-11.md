## Tradeoffs

| Choice | Benefit | Cost |
|---|---|---|
| Fix P0 drift in place rather than rewrite chapters | Readers keep stable URLs and structure | Some chapters carry 2025 framing alongside 2026 updates |
| Dated snapshots (model tiers, deprecation calendar) in normative docs | Actionable now | Must be re-verified quarterly; the profiler flags stale dates |
| Profiler scoring by document type | Fragments and kit prompts are not penalized for missing chapter sections | Scores are comparable only within a type |

## Anti-patterns

- Treating this map as a backlog of record. The issue tracker owns the work; this file owns the evidence and the rationale.
- Re-running research without diffing against this map. Start from the "Open" rows.
- Chasing a 100 average score. The duplicate-paragraph and outdated-term counts carry more information than the average.

## Enterprise considerations
